## The System Design Lifecycle

1. Understand the problem
2. Define requirements
3. Estimate capacity
4. Identify constraints
5. Design the simplest viable architecture
6. Find bottlenecks
7. Design for failure
8. Define consistency
9. Define latency objectives
10. Evaluate cost
11. Evolve the architecture
12. Validate the design
