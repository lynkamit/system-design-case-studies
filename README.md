# What This Repository Is Not

This repository is intentionally not:

- a collection of superficial architecture diagrams
- a list of technology buzzwords
- a set of memorized interview answers
- a collection of CRUD applications
- a "use Kubernetes everywhere" guide
- a "use microservices everywhere" guide
- a collection of theoretical patterns without context

The goal is to demonstrate engineering judgment.
